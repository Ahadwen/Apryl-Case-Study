Document upload: wireframe

Five states of one page. Identifiers are found and removed in the browser; only the anonymised text goes to Claude, which returns a fixed JSON shape that fills in the rest of the list. The patient then confirms or edits each detail, fixing it by re-uploading a clearer photo or typing it in (typed values are flagged on the claim).

Open questions

  1. How do we recognise the name and DOB? Proposed: the patient is logged in, so we already know them; we look for those exact values in the text (tolerant of formats like 3 Feb 1990 / 03.02.1990), which also proves the document is theirs. Patterns catch other identifiers (NHS no., phone, email, address).
